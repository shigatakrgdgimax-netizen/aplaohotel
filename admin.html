Configuración y puesta en marcha

Herramientas y notas técnicas para operar de forma segura.

Antes de usar con clientes reales: activa reglas seguras de Firestore, restringe las colecciones de administración a usuarios autenticados, verifica la disponibilidad en el servidor y configura copias de seguridad. No uses reglas abiertas en producción.

Cuenta conectada

Sesión:

Los usuarios se crean desde Firebase Console → Authentication → Users → Add user. No existe una contraseña predeterminada en el código.

Configuración de Firebase

El archivo admin.html usa Firebase Authentication y Cloud Firestore. Copia la configuración de tu aplicación web de Firebase en la constante firebaseConfig de ambos archivos: index.html y admin.html. Activa Authentication con correo/contraseña y crea las colecciones al guardar el primer registro.

Colecciones utilizadas: site (documento public), rooms, services, reservations.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /site/public {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /rooms/{id} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /services/{id} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /reservations/{id} {
      allow create: if true;
      allow read, update, delete: if request.auth != null;
    }
  }
}

Estas reglas son una base sencilla para pruebas, no bastan por sí solas para producción: una regla create abierta permite solicitudes anónimas y requiere validación adicional contra abuso. Antes de publicar, valida campos, limita tamaño y protege los datos personales.
